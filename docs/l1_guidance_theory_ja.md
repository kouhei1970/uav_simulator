# L1適応誘導理論

## 概要

L1適応誘導則は、固定翼無人航空機（UAV）専用に設計された非線形軌道追従アルゴリズムです。本ドキュメントでは、L1誘導の包括的な理論的基礎と実装の詳細を提供します。

## 1. はじめに

### 1.1 背景

L1誘導則は、Park、Deyst、How（2004年）が論文"A New Nonlinear Guidance Logic for Trajectory Tracking"で開発しました。この手法は、以下のような航空機の課題に対処します：

- 大きな横方向位置誤差
- コース角誤差
- 風による外乱
- 変化する対気速度

### 1.2 主な利点

1. **適応性**: 異なる対気速度に自動的に調整
2. **ロバスト性**: 大きな初期誤差を効果的に処理
3. **シンプル**: 優雅な幾何学的解釈
4. **実績**: 商用オートパイロット（ArduPilot、PX4）で広く使用

### 1.3 応用例

- 直線経路追従
- 円軌道追跡
- ウェイポイント航法
- 調査ミッション
- ロイターパターン

## 2. 数学的基礎

### 2.1 座標系

**北東下（NED）座標系**: 慣性基準座標系
- $p_n$: 北方向位置 [m]
- $p_e$: 東方向位置 [m]
- $p_d$: 下方向位置 [m]（高度の負値）

**コース角**: 地上軌道方向
$$\chi = \arctan2(v_e, v_n)$$

ここで、$v_n$、$v_e$は地上速度成分です。

### 2.2 L1距離パラメータ

L1距離は、誘導則が目標経路上で「どれだけ先を見る」かを決定する先読み距離です：

$$L_1 = \frac{1}{\pi} \zeta T V_a$$

ここで：
- $\zeta$: 減衰比（通常0.5-1.0）
- $T$: 周期パラメータ [s]（通常10-25秒）
- $V_a$: 対気速度 [m/s]

**物理的解釈**:
- $L_1$が大きい → より滑らかで穏やかな補正
- $L_1$が小さい → より厳密な追跡、より積極的な機動

**典型的な値**:
- 小型UAV（15 m/s）: $L_1 \approx 34$ m（$\zeta=0.707$、$T=15$ s）
- 中型UAV（25 m/s）: $L_1 \approx 56$ m（$\zeta=0.707$、$T=15$ s）

## 3. 直線経路追従

### 3.1 問題の定式化

与えられた条件：
- 始点$\mathbf{r}_s$と終点$\mathbf{r}_e$で定義される直線
- 現在位置$\mathbf{p}$
- 現在のコース角$\chi$
- 対気速度$V_a$

求めるもの：直線を追従するための横方向加速度指令$a_c$

### 3.2 幾何学的設定

**経路方向**:
$$\mathbf{q} = \frac{\mathbf{r}_e - \mathbf{r}_s}{|\mathbf{r}_e - \mathbf{r}_s|}$$

**経路のコース角**:
$$\chi_q = \arctan2(q_e, q_n)$$

**位置誤差ベクトル**:
$$\mathbf{r} = \mathbf{p} - \mathbf{r}_s$$

**クロストラック誤差**（経路からの垂直距離）:
$$e_{py} = \mathbf{r} \times \mathbf{q} = r_n q_e - r_e q_n$$

（2Dでは、これは外積のz成分です）

$e_{py}$が正の場合、航空機は経路の左側にあります。

### 3.3 直線に対するL1誘導則

横方向加速度指令は：

$$a_c = \frac{2 V_a^2}{L_1} \sin\left(\arctan2(-e_{py}, L_1)\right)$$

**導出**:

L1法則は、接近角に沿ってL1距離先の経路上の点に向かって航空機を駆動するベクトル場を作成することに基づいています。

速度$V_a$で半径$R$の円弧を追従するために必要な加速度は：
$$a = \frac{V_a^2}{R}$$

L1誘導の場合、有効半径はクロストラック誤差と先読み距離に関連します：
$$\sin(\eta) = \frac{-e_{py}}{L_1}$$

ここで、$\eta$は接近角です。

したがって：
$$a_c = \frac{2V_a^2}{L_1} \sin(\eta)$$

### 3.4 コース角誤差

コース角誤差は次のように計算できます：
$$\epsilon_\chi = \chi_q - \chi$$

$[-\pi, \pi]$の範囲に正規化されます。

### 3.5 収束特性

L1法則は以下を保証します：
1. **漸近安定性**: $t \rightarrow \infty$のとき$e_{py} \rightarrow 0$
2. **オーバーシュートなし**: パラメータが適切に調整されている場合
3. **指数収束**: 誤差が指数関数的に減少

## 4. 円軌道追従

### 4.1 問題の定式化

与えられた条件：
- 旋回中心$\mathbf{c} = [c_n, c_e, c_d]^T$
- 旋回半径$R$
- 旋回方向：CW（時計回り）またはCCW（反時計回り）
- 現在位置$\mathbf{p}$
- 現在のコース角$\chi$
- 対気速度$V_a$

求めるもの：軌道を追従するための横方向加速度指令$a_c$

### 4.2 幾何学的設定

**中心からの距離ベクトル**:
$$\mathbf{d} = [p_n - c_n, p_e - c_e]^T$$

**中心からの距離**:
$$d = |\mathbf{d}| = \sqrt{(p_n - c_n)^2 + (p_e - c_e)^2}$$

**中心からの角度**:
$$\alpha = \arctan2(p_e - c_e, p_n - c_n)$$

**半径誤差**:
$$e_r = d - R$$

$e_r$が正の場合は軌道の外側、負の場合は内側を意味します。

### 4.3 方向パラメータ

定義：
$$\lambda = \begin{cases}
+1 & \text{CW（時計回り）の場合} \\
-1 & \text{CCW（反時計回り）の場合}
\end{cases}$$

### 4.4 目標コース角

目標コース角は軌道への接線方向です：
$$\chi_q = \alpha + \lambda \frac{\pi}{2}$$

CW軌道の場合、これは半径方向の90°先です。
CCW軌道の場合、これは半径方向の90°後です。

### 4.5 軌道に対するL1誘導則

横方向加速度指令は2つの成分から構成されます：

$$a_c = a_{lateral} + a_{centripetal}$$

**横方向補正**（軌道に向かって駆動）:
$$a_{lateral} = \frac{2V_a^2}{L_1} \sin\left(\arctan2(\lambda e_r, L_1)\right)$$

**遠心加速度**（円運動を維持）:
$$a_{centripetal} = \lambda \frac{V_a^2}{R}$$

**合計指令**:
$$a_c = \frac{2V_a^2}{L_1} \sin\left(\arctan2(\lambda e_r, L_1)\right) + \lambda \frac{V_a^2}{R}$$

### 4.6 物理的解釈

- 遠心項は円運動を維持
- 横方向項は半径誤差を補正
- 軌道上（$e_r = 0$）では、遠心加速度のみが残る
- $\lambda$の符号が旋回方向を決定

## 5. ロール角指令の生成

### 5.1 協調旋回の関係

協調旋回（横滑りなし）では、横方向加速度は：

$$a = g \tan(\phi)$$

ここで：
- $g = 9.81$ m/s²: 重力加速度
- $\phi$: バンク角（ロール角）[rad]

### 5.2 ロール指令

横方向加速度指令から、バンク角を計算します：

$$\phi_c = \arctan\left(\frac{a_c}{g}\right)$$

### 5.3 バンク角制限

安全性と快適性のため、バンク角を制限します：

$$\phi_c = \text{saturate}(\phi_c, -\phi_{max}, \phi_{max})$$

典型的な制限：
- 小型UAV: $\phi_{max} = 45°$（0.785 rad）
- アクロバット: $\phi_{max} = 60°$（1.047 rad）
- 商用: $\phi_{max} = 30°$（0.524 rad）

## 6. パラメータ調整のガイドライン

### 6.1 L1周期（$T$）

**効果**:
- $T$が大きい → $L_1$が大きい → 穏やかな旋回 → 低速機に適している
- $T$が小さい → $L_1$が小さい → 厳密な追跡 → 機敏な機体に適している

**推奨値**:
- 低速/安定機: $T = 20-25$ s
- 中型機: $T = 15-20$ s
- 高速/機敏機: $T = 10-15$ s

### 6.2 L1減衰（$\zeta$）

**効果**:
- $\zeta = 0.707$（臨界減衰）: ほとんどの場合に最適
- $\zeta < 0.707$（減衰不足）: より速い応答、振動の可能性
- $\zeta > 0.707$（過減衰）: より遅い応答、振動なし

**推奨値**:
- 標準: $\zeta = 0.707$
- 風が強い条件: $\zeta = 0.8-1.0$
- 穏やかな条件: $\zeta = 0.6-0.7$

### 6.3 固定L1距離

あるいは、$L_1$を直接指定：

**経験則**:
$$L_1 = (2-5) \times V_a$$

例えば、15 m/sの場合：
- 保守的: $L_1 = 30$ m
- 標準: $L_1 = 45$ m
- 積極的: $L_1 = 75$ m

## 7. 安定性解析

### 7.1 直線追従のリアプノフ解析

リアプノフ候補関数を考えます：
$$V = \frac{1}{2} e_{py}^2$$

時間微分を取り、それが負定値であることを示すことで安定性を証明します。

**結果**: L1誘導則は直線追従に対して大域的漸近安定です。

### 7.2 軌道追従の安定性

円軌道の場合、同様の解析により以下が示されます：
- 内側ループ（半径制御）は安定
- 外側ループ（接線追跡）は安定
- $L_1 > 0$の場合、結合システムは安定

## 8. 他の手法との比較

### 8.1 Pure Pursuitとの比較

**L1の利点**:
- 対気速度変化への適応
- 大きな誤差の優れた処理
- よりスムーズな遷移

**Pure Pursuit**:
- より単純な実装
- 固定先読み距離

### 8.2 ベクトル場誘導との比較

**L1の利点**:
- 大きな誤差に対してより積極的
- 実証されたフィールド性能

**ベクトル場**:
- 経路から遠い場所でよりスムーズ
- より優れた理論的保証

### 8.3 PID制御との比較

**L1の利点**:
- 非線形（大きな誤差を処理）
- 積分ワインドアップなし
- 適応的な動作

**PID**:
- 小さな誤差に対して機能
- 調整経験が利用可能

## 9. 実装上の考慮事項

### 9.1 コース角の計算

利用可能な場合はGPS速度を使用：
$$\chi = \arctan2(v_e, v_n)$$

シミュレーションでは、NEDに投影された機体速度を使用：
$$\chi = \arctan2(v, u)$$

ここで、$u$、$v$はNEDに変換された機体座標系速度です。

### 9.2 風の補償

L1誘導は自然に風を処理します：
- ヘディング$\psi$ではなく、コース角$\chi$（地上軌道）を使用
- $L_1$計算における対気速度$V_a$
- 風の三角形が自動的に解決される

### 9.3 経路間の遷移

経路を切り替える場合：
1. 経路パラメータを即座に更新
2. $L_1$距離が自動的に適応
3. 特別なロジックは不要

### 9.4 数値的考慮事項

**角度のラッピング**: 常に角度を$[-\pi, \pi]$にラップ：
```python
def wrap_angle(angle):
    while angle > π:
        angle -= 2π
    while angle < -π:
        angle += 2π
    return angle
```

**中心での特異点**: 軌道の場合、ゼロ除算を避けるために$d > d_{min}$（例：0.1 m）を確認。

## 10. 計算例

### 10.1 直線の例

与えられた条件：
- $(0, 0)$から$(1000, 500)$ mまでの直線
- 航空機の位置$(200, 100)$ m
- コース角$\chi = 30°$
- 対気速度$V_a = 15$ m/s
- $L_1 = 35$ m

**ステップ1**: 経路方向
$$\mathbf{q} = \frac{1}{\sqrt{1000^2 + 500^2}} [1000, 500]^T = [0.894, 0.447]^T$$

**ステップ2**: クロストラック誤差
$$e_{py} = 200 \times 0.447 - 100 \times 0.894 = 89.4 - 89.4 = 0$$

航空機は経路上にあります！

**ステップ3**: 横方向加速度
$$a_c = \frac{2 \times 15^2}{35} \sin(\arctan2(0, 35)) = 0 \text{ m/s}^2$$

補正は不要です。

### 10.2 軌道の例

与えられた条件：
- 旋回中心$(400, 400)$ m
- 旋回半径$R = 60$ m
- 方向：CW（$\lambda = 1$）
- 航空機の位置$(450, 400)$ m
- コース角$\chi = 90°$（東）
- 対気速度$V_a = 15$ m/s
- $L_1 = 35$ m

**ステップ1**: 中心からの距離
$$d = \sqrt{(450-400)^2 + (400-400)^2} = 50 \text{ m}$$

**ステップ2**: 半径誤差
$$e_r = 50 - 60 = -10 \text{ m}$$

航空機は軌道の内側にあります。

**ステップ3**: 目標コース角
$$\alpha = \arctan2(0, 50) = 0°$$
$$\chi_q = 0° + 90° = 90°$$

**ステップ4**: 横方向加速度
$$a_{lateral} = \frac{2 \times 15^2}{35} \sin(\arctan2(-10, 35)) = 12.86 \times \sin(-15.9°) = -3.5 \text{ m/s}^2$$
$$a_{centripetal} = \frac{15^2}{60} = 3.75 \text{ m/s}^2$$
$$a_c = -3.5 + 3.75 = 0.25 \text{ m/s}^2$$

**ステップ5**: ロール指令
$$\phi_c = \arctan(0.25 / 9.81) = 1.5°$$

外側に移動するための小さな補正です。

## 11. 性能指標

### 11.1 定常状態誤差

直線の場合：
- 典型的: < 2 m
- 最良の場合: < 0.5 m

軌道の場合：
- 典型的: < 3 m半径誤差
- 最良の場合: < 1 m半径誤差

### 11.2 収束時間

大きな初期誤差（50 m）から：
- 50%削減: 〜10-15秒
- 90%削減: 〜30-40秒

### 11.3 風への感度

L1誘導は対気速度の50%までの風を処理します：
- 15 m/s対気速度: 7.5 m/sの風を処理
- クロストラック誤差がわずかに増加
- 不安定性なし

## 12. 高度なトピック

### 12.1 適応的L1

変化する条件に対して、$L_1$をオンラインで適応：
$$L_1(t) = f(V_a(t), \text{wind}(t), \text{error}(t))$$

### 12.2 経路遷移

線分間のスムーズな遷移：
- 角でフィレット経路
- 旋回に軌道セグメントを使用
- 最適遷移のためのDubins経路

### 12.3 3D拡張

3D経路への拡張：
- 高度制御ループを追加
- 横方向と垂直方向の誘導を分離
- 一定の対気速度を維持

## 14. まとめ

L1適応誘導則は以下を提供します：
- **ロバスト**な固定翼UAVの経路追従
- **シンプル**な幾何学的解釈
- 変化する飛行条件への**適応性**
- 実世界のアプリケーションでの**実証済み**性能

主要な方程式：
- L1距離: $L_1 = \frac{1}{\pi} \zeta T V_a$
- 直線追跡: $a_c = \frac{2 V_a^2}{L_1} \sin(\arctan2(-e_{py}, L_1))$
- 軌道追跡: $a_c = \frac{2V_a^2}{L_1} \sin(\arctan2(\lambda e_r, L_1)) + \lambda \frac{V_a^2}{R}$
- ロール指令: $\phi_c = \arctan(a_c / g)$

適切な調整（$\zeta \approx 0.707$、$T = 15$ s）により、L1誘導は広範囲の固定翼UAVアプリケーションに対して優れた追跡性能を提供します。
