# 固定翼UAV設計ガイド

## 形状と空力係数の関係

機体形状から空力係数へ、そして係数から形状へ

---

## 目次

1. 機体の基本構成要素
2. 主翼の設計と空力係数
3. 水平尾翼と縦安定性
4. 垂直尾翼と方向安定性
5. 重心位置とスタティックマージン
6. 空力係数の推算方法
7. 設計手順の実例

---

## このガイドの目標

✅ **機体形状から空力係数を推算できる**
- 翼面積、翼幅、尾翼サイズ → C_L_alpha, C_m_alpha など

✅ **空力係数から機体形状を決定できる**
- 目標の安定性（C_m_alpha = -0.5）→ 必要な尾翼サイズ

✅ **安定性を考慮した機体設計ができる**
- スタティックマージン、上反角、容積比の選定

# 1. 機体の基本構成要素

---

## 固定翼UAVの構成

<img src="plane.png" align="right" width="400px">

**主要構成要素：**
- **主翼**: 揚力発生、ロール制御（エルロン）
- **胴体**: ペイロード搭載、重心位置に影響
- **水平尾翼**: ピッチ安定性、ピッチ制御（エレベータ）
- **垂直尾翼**: 方向安定性、ヨー制御（ラダー）

---

## 主要な記号と単位

### 主翼パラメータ

| 記号 | 名称 | 単位 |
|------|------|------|
| S | 主翼面積 | m² |
| b | 翼幅 | m |
| c̄ | 平均翼弦長 | m |
| AR | アスペクト比 = b²/S | - |
| Γ | 上反角 | deg |

---

## 主要な記号と単位（続き）

### 尾翼パラメータ

| 記号 | 名称 |
|------|------|
| S_h | 水平尾翼面積 [m²] |
| l_h | テールアーム [m] |
| V̄_h | 水平尾翼容積比 = (l_h × S_h) / (S × c̄) |
| S_v | 垂直尾翼面積 [m²] |
| V̄_v | 垂直尾翼容積比 = (l_v × S_v) / (S × b) |

---

## 空力係数の符号規約

### 安定性の判断

| 係数 | 安定の条件 | 物理的意味 |
|------|-----------|-----------|
| C_m_alpha | **負** | 迎角増加で機首下げ |
| C_l_beta | **負** | 横滑りで復元ロール |
| C_n_beta | **正** | 横滑りで機首が風向きへ |
| C_m_q | **負** | ピッチ運動を減衰 |
| C_l_p | **負** | ロール運動を減衰 |
| C_n_r | **負** | ヨー運動を減衰 |

---

# 2. 主翼の設計と空力係数

---

## 主翼面積の決定

### 必要翼面積の計算

```
S = (m × g) / (0.5 × ρ × V² × C_L) × 安全率
```

**設計例（小型UAV）:**
- 質量 m = 1.7 kg
- 巡航速度 V = 15 m/s
- 目標 C_L = 0.5

```
S = (1.7 × 9.81) / (0.5 × 1.225 × 15² × 0.5) × 1.2
  ≈ 0.28 m²
```

---

## アスペクト比の選択

```
AR = b² / S
```

| アスペクト比 | 特性 | 用途 |
|-------------|------|------|
| AR > 10 | 誘導抗力小、長時間飛行 | グライダー |
| AR = 7～10 | バランス型 | 一般的なUAV ✓ |
| AR < 7 | 機動性重視 | 高速機 |

**設計例:**
- 目標 AR = 9.0, S = 0.28 m²
- → b = √(9.0 × 0.28) ≈ 1.59 m

---

## 上反角と横安定性

### 上反角の効果

```
C_l_beta ≈ -C_L_alpha × (Γ / 57.3) × k_Γ
```

| 上反角 | C_l_beta | 安定性 |
|--------|----------|--------|
| 0° | 約 0 | 中立 |
| 3°～5° | -0.10 ～ -0.15 | 安定 ✓ |
| 6°～8° | -0.15 ～ -0.20 | 高安定 |

**設計例:** Γ = 4° → C_l_beta ≈ -0.15

---

## 揚力傾斜の推算

### 理論式（3次元翼）

```
C_L_alpha ≈ (2π) / (1 + 2/AR)  [1/rad]
```

**設計例:** AR = 9.0

```
C_L_alpha ≈ 6.283 / (1 + 2/9.0) ≈ 5.14 /rad (理論値)
```

---

## 揚力傾斜の推算（続き）

### 粘性効果の補正

理論値から15%減少:
```
C_L_alpha ≈ 5.14 × 0.85 ≈ 4.37 /rad
```

**シミュレータ設定値:** C_L_alpha = 4.00 /rad ✓

---

# 3. 水平尾翼と縦安定性

---

## 水平尾翼容積比

### 標準的な範囲

```
V̄_h = (l_h × S_h) / (S × c̄)
```

| 機体タイプ | V̄_h | 特性 |
|------------|------|------|
| 高安定性 | 0.6～0.8 | 初心者向け |
| 標準 | 0.5～0.6 | 一般的なUAV ✓ |
| 高機動性 | 0.3～0.5 | アクロバット |

**設計例:** V̄_h = 0.45, l_h = 0.60 m
→ S_h = 0.037 m²

---

## ピッチ静安定微係数

### 全機の C_m_alpha

```
C_m_alpha = C_m_alpha_wb + C_m_alpha_h
```

**主翼+胴体の寄与:**
```
C_m_alpha_wb ≈ -K_n × C_L_alpha
              = -0.10 × 4.0 = -0.40
```

**水平尾翼の寄与:**
```
C_m_alpha_h = -η_h × V̄_h × C_L_alpha_h × (1 - dε/dα)
            = -0.95 × 0.45 × 3.5 × 0.6
            = -0.90
```

---

## ピッチ安定性の計算結果

**理論値:**
```
C_m_alpha_total = -0.40 + (-0.90) = -1.30 /rad
```

**実効値（干渉効果を考慮）:**
```
C_m_alpha ≈ -1.30 × 0.40 ≈ -0.52 /rad
```

**シミュレータ設定値:** C_m_alpha = -0.50 /rad ✓

---

## ピッチダンピング

### 推算式

```
C_m_q ≈ -2 × η_h × V̄_h × C_L_alpha_h × (l_h / c̄)
```

**設計例:**
```
C_m_q ≈ -2 × 0.95 × 0.45 × 3.5 × 3.41
      ≈ -10.2 (理論値)
```

**実効値:** C_m_q ≈ -4.0 ✓

---

## エレベータ効果

### 推算式（本シミュレータの符号規約）

```
C_m_delta_e = -η_h × V̄_h × C_L_delta_e_h
```

**注意:** 正のエレベータ（後縁下げ）で機首下げ
→ C_m_delta_e は**負**

**設計例:**
```
C_m_delta_e = -0.95 × 0.45 × 0.875 × 1.5
            ≈ -0.56 /rad
```

**シミュレータ設定値:** C_m_delta_e = -0.55 /rad ✓

---

# 4. 垂直尾翼と方向安定性

---

## 垂直尾翼容積比

### 標準的な範囲

```
V̄_v = (l_v × S_v) / (S × b)
```

| 機体タイプ | V̄_v | 特性 |
|------------|------|------|
| 高安定性 | 0.04～0.06 | トレーナー |
| 標準 | 0.02～0.04 | 一般的なUAV ✓ |
| 低安定性 | 0.01～0.02 | 戦闘機タイプ |

**設計例:** V̄_v = 0.04, l_v = 0.60 m
→ S_v = 0.030 m²

---

## 風見安定性

### 推算式

```
C_n_beta = η_v × V̄_v × C_L_alpha_v + C_n_beta_fus
```

**設計例:**
```
C_n_beta_v = 0.95 × 0.04 × 3.5 = 0.133
```

胴体の寄与 (+0.15) を加えて:
```
C_n_beta = 0.133 + 0.15 = 0.28 ≈ 0.30 /rad
```

**シミュレータ設定値:** C_n_beta = 0.30 /rad ✓

---

## ヨーダンピング

### 推算式

```
C_n_r ≈ -2 × η_v × V̄_v × C_L_alpha_v × (l_v / b)
```

**設計例:**
```
C_n_r ≈ -2 × 0.95 × 0.04 × 3.5 × 0.377
      ≈ -0.099 (垂直尾翼のみ)
```

主翼・胴体の寄与を加えて:
```
C_n_r ≈ -0.40
```

**シミュレータ設定値:** C_n_r = -0.40 ✓

---

# 5. 重心位置とスタティックマージン

---

## スタティックマージンの定義

```
K_n = (x_ac - x_cg) / c̄
```

- x_ac: 全機空力中心のX座標
- x_cg: 重心のX座標

### 推奨値

| 用途 | K_n | C_m_alpha (概算) |
|------|-----|------------------|
| トレーナー | 0.15～0.25 | -0.6 ～ -1.0 |
| 一般的なUAV | 0.05～0.15 | -0.2 ～ -0.6 ✓ |
| 高機動機 | -0.05～0.05 | 0.2 ～ -0.2 |

---

## 重心位置の決定

### 主翼前縁からの位置

```
x_cg = x_le_w + (0.25 + K_n) × c̄
```

**設計例:**
- 目標 K_n = 0.10
- c̄ = 0.176 m

```
x_cg = (0.25 + 0.10) × 0.176
     = 0.35 × 0.176
     = 61.6 mm （主翼前縁から）
```

重心は翼弦の **35% 位置** に設定

---

## 重量配分の例

| 部品 | 重量 [g] | X座標 [mm] | モーメント [g⋅mm] |
|------|----------|------------|-------------------|
| バッテリー | 450 | 40 | 18,000 |
| FC | 50 | 60 | 3,000 |
| モーター | 120 | 10 | 1,200 |
| サーボ×4 | 40 | 50 | 2,000 |

---

## 重量配分の例（続き）

| 部品 | 重量 [g] | X座標 [mm] | モーメント [g⋅mm] |
|------|----------|------------|-------------------|
| 機体構造 | 800 | 70 | 56,000 |
| カメラ | 100 | 30 | 3,000 |
| ペイロード | 140 | 80 | 11,200 |
| **合計** | **1700** | - | **94,400** |

**重心位置:** x_cg = 94,400 / 1,700 = 55.5 mm

# 6. 空力係数の推算方法まとめ

---

## 形状 → 係数の変換

### 縦系（Longitudinal）

| 係数 | 推算式 | 主要影響因子 |
|------|--------|--------------|
| C_L_alpha | (2π)/(1+2/AR) × 0.85 | AR |
| C_L_0 | C_L_alpha × i_w + 0.15 | i_w |
| C_m_alpha | -K_n × C_L_alpha - ... | K_n, V̄_h |
| C_m_q | -2 × η_h × V̄_h × ... | V̄_h, l_h |
| C_m_delta_e | -η_h × V̄_h × ... | V̄_h |

---

## 形状 → 係数の変換（続き）

### 横・方向系（Lateral-Directional）

| 係数 | 推算式 | 主要影響因子 |
|------|--------|--------------|
| C_l_beta | -C_L_alpha × (Γ/57.3) × 0.9 | Γ（上反角） |
| C_l_p | -C_L_alpha / 12 | AR |
| C_n_beta | η_v × V̄_v × C_L_alpha_v + ... | V̄_v |
| C_n_r | -2 × η_v × V̄_v × ... | V̄_v, l_v |

---

## 係数 → 形状の逆算

### 目標 C_m_alpha = -0.50 を実現する例

**ステップ1:** スタティックマージンを決定
```
K_n = -C_m_alpha / C_L_alpha
    = 0.50 / 4.0 = 0.125
```

**ステップ2:** 水平尾翼の寄与を決定
```
C_m_alpha_h = -0.50 - (-0.50) = 0
```
→ より安定にするには V̄_h を調整

---

## 係数 → 形状の逆算（続き）

### 目標 C_n_beta = 0.30 を実現する例

**ステップ1:** 垂直尾翼の寄与を決定
```
C_n_beta_v = 0.30 - 0.15 = 0.15
```

**ステップ2:** 必要な V̄_v を計算
```
V̄_v = 0.15 / (0.95 × 3.5) = 0.045
```

**ステップ3:** 垂直尾翼面積を計算
```
S_v = (0.045 × 0.28 × 1.59) / 0.60 = 0.0334 m²
```

---

# 7. 設計手順の実例

---

## 要求仕様

**目標UAVの仕様:**
- 全備重量: 1.7 kg
- 巡航速度: 15 m/s
- 飛行時間: 30分
- 安定性: 標準（初心者でも飛ばせる程度）

---

## ステップ1：主翼の設計

### 翼面積
```
S = (1.7 × 9.81) / (0.5 × 1.225 × 15² × 0.5) × 1.2
  = 0.288 m²
```
**採用値:** S = 0.28 m²

### 翼幅とアスペクト比
AR = 9 を選択
```
b = √(9 × 0.28) = 1.59 m
c̄ = 0.28 / 1.59 = 0.176 m
```
**採用値:** b = 1.6 m, c̄ = 0.175 m

---

## ステップ2：主翼パラメータ

### 上反角
Γ = 4° を選択
```
C_l_beta ≈ -4.0 × (4/57.3) × 0.9 = -0.25 (理論)
```
**実効値:** C_l_beta ≈ -0.15 ✓

### 主翼取付角
i_w = 2° とする
```
C_L_0 = 4.0 × 0.0349 + 0.15 = 0.29 ≈ 0.30 ✓
```

---

## ステップ3：重心位置の決定

スタティックマージン K_n = 0.10 を目標
```
x_cg = 0.35 × 0.175 = 0.061 m
     = 61 mm（主翼前縁から）
```

### 関係式
```
C_m_alpha ≈ -K_n × C_L_alpha
          = -0.10 × 4.0
          = -0.40 (主翼+胴体)
```

---

## ステップ4：水平尾翼の設計

### 容積比
V̄_h = 0.45 を選択

### テールアーム
l_h = 0.60 m とする

### 水平尾翼面積
```
S_h = (0.45 × 0.28 × 0.175) / 0.60
    = 0.037 m²
```

---

## ステップ5：空力係数の検証

### ピッチ安定性
```
C_m_alpha_wb = -0.40
C_m_alpha_h = -0.90
C_m_alpha_total = -1.30 (理論)
```
**実効値:** C_m_alpha ≈ -0.50 ✓

### ピッチダンピング
```
C_m_q = -10.2 (理論)
```
**実効値:** C_m_q ≈ -4.0 ✓

---

## ステップ6：垂直尾翼の設計

### 容積比
V̄_v = 0.04 を選択

### 垂直尾翼面積
```
S_v = (0.04 × 0.28 × 1.6) / 0.60
    = 0.030 m²
```

### 方向安定性
```
C_n_beta = 0.133 + 0.15 = 0.28 ≈ 0.30 ✓
C_n_r ≈ -0.40 ✓
```

---

## 設計結果のまとめ

### 機体パラメータ

| パラメータ | 設計値 |
|-----------|-------|
| 主翼面積 S | 0.28 m² |
| 翼幅 b | 1.6 m |
| 上反角 Γ | 4° |
| 水平尾翼面積 S_h | 0.037 m² |
| 垂直尾翼面積 S_v | 0.030 m² |
| 重心位置 x_cg | 61 mm |

---

## 設計結果のまとめ（続き）

### 空力係数の検証

| 係数 | 設計値 | シミュレータ | 判定 |
|------|--------|------------|------|
| C_L_alpha | 4.37 | 4.00 | ✓ |
| C_L_0 | 0.29 | 0.30 | ✓ |
| C_m_alpha | -0.52 | -0.50 | ✓ |
| C_m_q | -10.2×0.4 | -4.0 | ✓ |
| C_l_beta | -0.25×0.6 | -0.15 | ✓ |
| C_n_beta | 0.28 | 0.30 | ✓ |

**すべての係数が妥当な範囲に収まっている！**

# まとめ

---

## 設計の流れ

1. **要求仕様の定義** → 質量、速度、安定性
2. **主翼の設計** → S, b, AR, Γ
3. **重心位置の決定** → K_n, x_cg
4. **水平尾翼の設計** → V̄_h, S_h, l_h
5. **垂直尾翼の設計** → V̄_v, S_v, l_v
6. **空力係数の計算** → C_L_alpha, C_m_alpha など
7. **シミュレーションで検証** → 必要に応じて調整

---

## キーポイント

✅ **形状 → 係数**
- 理論式と経験則を組み合わせて推算
- 干渉効果で理論値の40～60%程度に

✅ **係数 → 形状**
- 目標係数から必要な容積比を逆算
- スタティックマージンで重心位置を調整

✅ **反復設計**
- 最初の設計で完璧を目指さない
- シミュレーションで検証して改善

---

## クイックリファレンス

### 典型的な設計値（小型UAV）

| パラメータ | 推奨範囲 |
|-----------|---------|
| アスペクト比 AR | 7～10 |
| 上反角 Γ | 3°～5° |
| 水平尾翼容積比 V̄_h | 0.4～0.6 |
| 垂直尾翼容積比 V̄_v | 0.03～0.05 |
| スタティックマージン K_n | 0.05～0.15 |
