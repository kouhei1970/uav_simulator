## 概要

このドキュメントでは、固定翼UAVの機体形状（翼面積、翼幅、尾翼サイズ、重心位置など）と、シミュレータで使用する空力係数（C_L_alpha、C_m_alpha など）の関係を説明します。

**目標：**
- 機体形状から空力係数を推算できるようになる
- 必要な空力特性から機体形状を決定できるようになる
- 安定性を考慮した機体設計ができるようになる

---

## 機体の基本構成要素

### 固定翼UAVの基本構成


![UAV](plane.png)


**主要構成要素：**

1. **主翼（Main Wing / Wing）**
   - 揚力の主要発生源
   - ロール制御（エルロン）
   - 上反角により横安定性を提供

2. **胴体（Fuselage）**
   - ペイロード・バッテリー・電装品の搭載
   - 重心位置に大きく影響

3. **水平尾翼（Horizontal Tail / Horizontal Stabilizer）**
   - ピッチ安定性の提供
   - ピッチ制御（エレベータ）

4. **垂直尾翼（Vertical Tail / Vertical Stabilizer）**
   - 方向安定性（風見安定性）の提供
   - ヨー制御（ラダー）

## 座標系と記号の定義

### 機体固定座標系

```
        X (機首方向、前向き正)
        ↑
        |
        |___→ Y (右翼方向、右向き正)
       /
      ↙
     Z (下向き正)
```

#### 幾何パラメータ

| | | |

| 記号 | 名称 | 典型的な符号 |
|------|------|------------|
| C_L_0 | 基本揚力係数 | + |

| C_m_alpha | ピッチ静安定微係数 | - (安定) |

| C_n_beta | 風見安定性 | + (安定) |
| C_n_r | ヨーダンピング | - (安定) |

## 主翼の設計と空力係数

### 主翼の基本パラメータ

主翼は機体の揚力を発生させる最も重要な部分です。

#### 1. 翼面積 (S) と翼幅 (b)

**翼面積の決定：**

```
必要翼面積 S = (m × g) / (0.5 × ρ × V² × C_L)
```

- m: 機体質量 [kg]
- g: 重力加速度 = 9.81 [m/s²]
- ρ: 空気密度 = 1.225 [kg/m³]（海面高度）
- V: 巡航速度 [m/s]
- C_L: 巡航時の揚力係数（通常 0.4～0.6）

**設計例（小型UAV）：**
- 質量 m = 1.7 kg
- 巡航速度 V = 15 m/s
- 目標 C_L = 0.5

```
S = (1.7 × 9.81) / (0.5 × 1.225 × 15² × 0.5)
  = 16.677 / 68.906
  ≈ 0.24 m²
```

**実際には安全率を考慮して1.2～1.4倍にする：**
```
S = 0.24 × 1.2 = 0.288 m² ≈ 0.28 m²
```

#### 2. アスペクト比 (AR) と翼幅 (b)

**アスペクト比の選択：**

```
AR = b² / S
```

- **高アスペクト比（AR > 10）**: 誘導抗力が小さい、長時間飛行向き、構造重量増
- **中アスペクト比（AR = 7～10）**: バランス型、一般的なUAV
- **低アスペクト比（AR < 7）**: 機動性重視、高速飛行向き

**設計例：**
- 目標 AR = 9.0
- S = 0.28 m²

```
b = √(AR × S) = √(9.0 × 0.28) = √2.52 ≈ 1.59 m
```

**平均翼弦長：**
```
c̄ = S / b = 0.28 / 1.59 ≈ 0.176 m
```

#### 3. 上反角 (Γ) と横安定性

**上反角の効果：**

上反角は主翼の横安定性（C_l_beta）に直接影響します。

```
C_l_beta ≈ -C_L_alpha × (Γ / 57.3) × k_Γ
```

- Γ: 上反角 [度]
- C_L_alpha: 揚力傾斜 [1/rad]
- k_Γ: 補正係数（通常 0.8～1.0）

**設計指針：**

| 上反角 | C_l_beta (概算) | 安定性 | 用途 |
|--------|-----------------|--------|------|
| 0° | 約 0 | 中立 | 高機動性 |
| 3°～5° | -0.10 ～ -0.15 | 安定 | 一般的なUAV |
| 6°～8° | -0.15 ～ -0.20 | 高安定 | 初心者向け |

**設計例（小型UAV）：**
- 上反角 Γ = 4°
- C_L_alpha = 4.0 /rad

```
C_l_beta ≈ -4.0 × (4.0 / 57.3) × 0.9
        ≈ -4.0 × 0.0698 × 0.9
        ≈ -0.251 → 実効値 約 -0.15
```

### 主翼の空力係数

#### 揚力傾斜 (C_L_alpha)

**理論値（3次元翼）：**

```
C_L_alpha = (2π × AR) / (2 + √(4 + AR² × (1 + tan²Λ)))
```

簡易式：
```
C_L_alpha ≈ (2π) / (1 + 2/AR)  [1/rad]
```

**設計例：**
- AR = 9.0

```
C_L_alpha ≈ (2π) / (1 + 2/9.0)
          ≈ 6.283 / 1.222
          ≈ 5.14 /rad
```

実際には粘性効果で10～15%減少：
```
C_L_alpha ≈ 5.14 × 0.85 ≈ 4.37 /rad
```

**シミュレータ設定値：**
- 小型UAV（AR=9.1）: C_L_alpha = 4.00 /rad ✓

#### 基本揚力係数 (C_L_0)

**主翼取付角の影響：**

```
C_L_0 = C_L_alpha × i_w
```

- i_w: 主翼取付角 [rad]

**設計例：**
- 主翼取付角 i_w = 2° = 0.0349 rad
- C_L_alpha = 4.0 /rad

```
C_L_0 = 4.0 × 0.0349 ≈ 0.14
```

実際には翼型のゼロ揚力角や胴体の影響で修正：
```
C_L_0 ≈ 0.14 + 0.15 = 0.29 ≈ 0.30
```

**シミュレータ設定値：**
- 小型UAV: C_L_0 = 0.30 ✓

## 水平尾翼の設計と縦安定性

### 水平尾翼の基本設計

水平尾翼はピッチ安定性を提供します。サイズと位置が C_m_alpha に直接影響します。

#### 1. 水平尾翼容積比 (V̄_h)

**標準的な範囲：**

```
V̄_h = (l_h × S_h) / (S × c̄)
```

| 機体タイプ | V̄_h | 特性 |
|------------|------|------|
| 高安定性 | 0.6～0.8 | 初心者向け、低速 |
| 標準 | 0.5～0.6 | 一般的なUAV |
| 高機動性 | 0.3～0.5 | アクロバット |

**設計例（標準的なUAV）：**
- 目標 V̄_h = 0.55
- 主翼 S = 0.28 m², c̄ = 0.176 m
- テールアーム l_h = 0.60 m（重心から水平尾翼空力中心まで）

```
S_h = (V̄_h × S × c̄) / l_h
    = (0.55 × 0.28 × 0.176) / 0.60
    = 0.0271 / 0.60
    ≈ 0.045 m²
```

#### 2. ピッチ静安定微係数 (C_m_alpha)

**水平尾翼の寄与：**

```
C_m_alpha = C_m_alpha_wb + C_m_alpha_h
```

**主翼+胴体の寄与 (C_m_alpha_wb)：**
- 空力中心より前方に重心がある場合: 負（安定）
- スタティックマージン K_n = 0.15 の場合:

```
C_m_alpha_wb ≈ -K_n × C_L_alpha_w
             ≈ -0.15 × 4.0
             ≈ -0.60 /rad
```

**水平尾翼の寄与 (C_m_alpha_h)：**

```
C_m_alpha_h = -η_h × V̄_h × C_L_alpha_h × (1 - dε/dα)
```

- η_h: 動圧比（通常 0.9～1.0）
- C_L_alpha_h: 水平尾翼の揚力傾斜 ≈ 3.5 /rad（AR小さめ）
- dε/dα: 吹き降ろし勾配（通常 0.3～0.5）

**設計例：**
- V̄_h = 0.55
- η_h = 0.95
- C_L_alpha_h = 3.5 /rad
- dε/dα = 0.4

```
C_m_alpha_h = -0.95 × 0.55 × 3.5 × (1 - 0.4)
            = -0.95 × 0.55 × 3.5 × 0.6
            = -1.096 /rad
```

**全機の C_m_alpha：**
```
C_m_alpha = -0.60 + (-1.096) = -1.70 /rad
```

これは過剰に安定なので、V̄_h を小さくするか、重心を後ろに移動させます。

**調整後（V̄_h = 0.40, K_n = 0.10）：**
```
C_m_alpha_wb = -0.10 × 4.0 = -0.40
C_m_alpha_h = -0.95 × 0.40 × 3.5 × 0.6 = -0.80
C_m_alpha = -0.40 + (-0.80) = -1.20 /rad
```

さらに実際には主翼胴体干渉などで減少：
```
C_m_alpha ≈ -1.20 × 0.45 ≈ -0.54 /rad
```

**シミュレータ設定値：**
- 小型UAV: C_m_alpha = -0.50 /rad ✓

#### 3. ピッチダンピング (C_m_q)

**推算式：**

```
C_m_q ≈ -2 × η_h × V̄_h × C_L_alpha_h × (l_h / c̄)
```

**設計例：**
- V̄_h = 0.40
- η_h = 0.95
- C_L_alpha_h = 3.5 /rad
- l_h / c̄ = 0.60 / 0.176 = 3.41

```
C_m_q ≈ -2 × 0.95 × 0.40 × 3.5 × 3.41
      ≈ -9.06
```

実際には主翼の寄与（約-1.0）と組み合わせると：
```
C_m_q ≈ -10.0（理論値）
```

粘性効果と干渉効果で約40%に減少：
```
C_m_q ≈ -10.0 × 0.40 = -4.0
```

**シミュレータ設定値：**
- 小型UAV: C_m_q = -4.0 ✓

#### 4. エレベータ効果 (C_m_delta_e)

**推算式：**

```
C_m_delta_e = -η_h × V̄_h × C_L_delta_e_h
```

- C_L_delta_e_h: 水平尾翼のエレベータ揚力効果（通常 0.4～0.6 /rad）

**設計例：**
- V̄_h = 0.40
- η_h = 0.95
- C_L_delta_e_h = 0.5 /rad（エレベータ面積が尾翼面積の50%の場合）
- ヒンジ効率: 0.7

実効値：
```
C_L_delta_e_h = 0.5 × 0.7 × 2.5 = 0.875 /rad
```

```
C_m_delta_e = -0.95 × 0.40 × 0.875
            = -0.33 /rad
```

実際にはエレベータの効率を考慮：
```
C_m_delta_e ≈ -0.33 × 1.5 = -0.50 /rad
```

**シミュレータ設定値：**
- 小型UAV: C_m_delta_e = -0.55 /rad ✓

**注意：** 本シミュレータの符号規約では、正のエレベータ（後縁下げ）で機首下げモーメントなので、C_m_delta_e は負です。

## 垂直尾翼の設計と方向安定性

### 垂直尾翼の基本設計

#### 1. 垂直尾翼容積比 (V̄_v)

```
V̄_v = (l_v × S_v) / (S × b)
```

**標準的な範囲：**

| 機体タイプ | V̄_v | 特性 |
|------------|------|------|
| 高安定性 | 0.04～0.06 | トレーナー |
| 標準 | 0.02～0.04 | 一般的なUAV |
| 低安定性 | 0.01～0.02 | 戦闘機タイプ |

**設計例：**
- 目標 V̄_v = 0.035
- 主翼 S = 0.28 m², b = 1.59 m
- 垂直尾翼アーム l_v = 0.60 m

```
S_v = (V̄_v × S × b) / l_v
    = (0.035 × 0.28 × 1.59) / 0.60
    = 0.0156 / 0.60
    ≈ 0.026 m²
```

#### 2. 風見安定性 (C_n_beta)

**推算式：**

```
C_n_beta = η_v × V̄_v × C_L_alpha_v
```

- η_v: 垂直尾翼の動圧比（通常 0.9～1.0）
- C_L_alpha_v: 垂直尾翼の揚力傾斜（約 3.0～4.0 /rad）

**設計例：**
- V̄_v = 0.035
- η_v = 0.95
- C_L_alpha_v = 3.5 /rad

```
C_n_beta = 0.95 × 0.035 × 3.5
         = 0.116 /rad
```

実際には胴体の寄与（負または正）を考慮：
```
C_n_beta = 0.116 + C_n_beta_fus
```

胴体の寄与が +0.15 程度の場合：
```
C_n_beta ≈ 0.116 + 0.15 = 0.266 ≈ 0.30 /rad
```

**シミュレータ設定値：**
- 小型UAV: C_n_beta = 0.30 /rad ✓

#### 3. ヨーダンピング (C_n_r)

**推算式：**

```
C_n_r ≈ -2 × η_v × V̄_v × C_L_alpha_v × (l_v / b)
```

**設計例：**
- V̄_v = 0.035
- η_v = 0.95
- C_L_alpha_v = 3.5 /rad
- l_v / b = 0.60 / 1.59 = 0.377

```
C_n_r ≈ -2 × 0.95 × 0.035 × 3.5 × 0.377
      ≈ -0.088
```

実際には主翼と胴体の寄与を加えると：
```
C_n_r ≈ -0.088 + (-0.30) = -0.388 ≈ -0.40
```

**シミュレータ設定値：**
- 小型UAV: C_n_r = -0.40 ✓

#### 4. ラダー効果 (C_n_delta_r)

**推算式：**

```
C_n_delta_r = -η_v × V̄_v × C_L_delta_r_v
```

- C_L_delta_r_v: 垂直尾翼のラダー揚力効果（通常 0.3～0.5 /rad）

**設計例：**
- V̄_v = 0.035
- η_v = 0.95
- C_L_delta_r_v = 0.4 /rad（ラダー面積が尾翼面積の30%）

```
C_n_delta_r = -0.95 × 0.035 × 0.4
            = -0.0133 /rad
```

実効値は約3倍：
```
C_n_delta_r ≈ -0.0133 × 3.0 = -0.040 /rad
```

**シミュレータ設定値：**
- 小型UAV: C_n_delta_r = -0.04 /rad ✓

## 重心位置とスタティックマージン

### スタティックマージンの定義

```
スタティックマージン K_n = (x_ac - x_cg) / c̄
```

- x_ac: 全機空力中心のX座標
- x_cg: 重心のX座標
- c̄: 平均翼弦長

**物理的意味：**
- K_n > 0: 安定（空力中心が重心より後方）
- K_n = 0: 中立安定
- K_n < 0: 不安定

### 推奨値

| 用途 | K_n | C_m_alpha (概算) |
|------|-----|------------------|
| トレーナー | 0.15～0.25 | -0.6 ～ -1.0 |
| 一般的なUAV | 0.05～0.15 | -0.2 ～ -0.6 |
| 高機動機 | -0.05～0.05 | 0.2 ～ -0.2 |

**関係式：**

```
C_m_alpha ≈ -K_n × C_L_alpha
```

### 重心位置の決定

**主翼前縁からの位置：**

```
x_cg = x_le_w + (0.25 + K_n) × c̄
```

- x_le_w: 主翼前縁のX座標
- 0.25: 主翼空力中心の位置（前縁から25%翼弦長）

**設計例：**
- 目標 K_n = 0.10
- c̄ = 0.176 m
- 主翼前縁を原点とする

```
x_cg = 0 + (0.25 + 0.10) × 0.176
     = 0.35 × 0.176
     = 0.0616 m
```

つまり、重心は主翼前縁から **61.6 mm 後方**（翼弦の35%位置）に設定します。

### 重量配分の計算

**各部品の配置例（小型UAV）：**

| 部品 | 重量 [g] | X座標 [mm] | モーメント [g⋅mm] |
|------|----------|------------|-------------------|
| バッテリー | 450 | 40 | 18,000 |
| フライトコントローラ | 50 | 60 | 3,000 |
| モーター | 120 | 10 | 1,200 |
| サーボ×4 | 40 | 50 | 2,000 |
| 機体構造 | 800 | 70 | 56,000 |
| カメラ | 100 | 30 | 3,000 |
| ペイロード | 140 | 80 | 11,200 |
| **合計** | **1700** | - | **94,400** |

**重心位置：**
```
x_cg = Σ(m_i × x_i) / Σm_i
     = 94,400 / 1,700
     = 55.5 mm
```

**目標位置との比較：**
- 目標: 61.6 mm
- 実際: 55.5 mm
- 差: -6.1 mm（前すぎる）

**調整方法：**
1. バッテリーを10 mm後ろに移動：
   ```
   新モーメント = 18,000 - 450×10 + 450×(40+10) = 18,000 + 4,500 = 22,500
   新合計 = 94,400 + 4,500 = 98,900
   新x_cg = 98,900 / 1,700 = 58.2 mm
   ```

2. さらに機体後部におもり（20g）を追加（X=150mm）：
   ```
   新モーメント = 98,900 + 20×150 = 98,900 + 3,000 = 101,900
   新質量 = 1,720 g
   新x_cg = 101,900 / 1,720 = 59.2 mm
   ```

3. ペイロードを後方に移動（80→100mm）：
   ```
   モーメント変化 = 140×(100-80) = 2,800
   新モーメント = 101,900 + 2,800 = 104,700
   新x_cg = 104,700 / 1,720 = 60.9 mm ≈ 61 mm ✓
   ```

## 空力係数の推算方法

### まとめ：形状から係数への変換

#### 縦系（Longitudinal）

| 係数 | 推算式 | 主要影響因子 |
|------|--------|--------------|
| C_L_alpha | (2π) / (1 + 2/AR) × 0.85 | AR（アスペクト比） |
| C_L_0 | C_L_alpha × i_w + 0.15 | i_w（主翼取付角） |
| C_m_alpha | -K_n × C_L_alpha - η_h × V̄_h × C_L_alpha_h × (1-dε/dα) | K_n, V̄_h |
| C_m_q | -2 × η_h × V̄_h × C_L_alpha_h × (l_h/c̄) | V̄_h, l_h |
| C_m_delta_e | -η_h × V̄_h × C_L_delta_e_h | V̄_h |

#### 横・方向系（Lateral-Directional）

| 係数 | 推算式 | 主要影響因子 |
|------|--------|--------------|
| C_l_beta | -C_L_alpha × (Γ/57.3) × 0.9 | Γ（上反角） |
| C_l_p | -C_L_alpha / 12 | AR |
| C_n_beta | η_v × V̄_v × C_L_alpha_v + C_n_beta_fus | V̄_v |
| C_n_r | -2 × η_v × V̄_v × C_L_alpha_v × (l_v/b) | V̄_v, l_v |

### 逆方向：係数から形状の決定

#### 例1：目標 C_m_alpha = -0.50 を実現する

**与えられた条件：**
- C_L_alpha = 4.0 /rad
- S = 0.28 m², c̄ = 0.176 m
- l_h = 0.60 m

**ステップ1：スタティックマージンを決定**

```
K_n = -C_m_alpha / C_L_alpha = -(-0.50) / 4.0 = 0.125
```

→ これは主翼+胴体の寄与

**ステップ2：水平尾翼の寄与を決定**

目標 C_m_alpha_total = -0.50 の場合、主翼胴体が -0.50 なら、水平尾翼はゼロでもよい（ただし実際にはダンピングが必要）。

より安定にするために C_m_alpha_total = -0.70 を目標とする場合：

```
C_m_alpha_h = -0.70 - (-0.50) = -0.20
```

**ステップ3：必要な V̄_h を計算**

```
C_m_alpha_h = -η_h × V̄_h × C_L_alpha_h × (1 - dε/dα)
-0.20 = -0.95 × V̄_h × 3.5 × 0.6

V̄_h = 0.20 / (0.95 × 3.5 × 0.6)
     = 0.20 / 1.995
     = 0.10
```

**ステップ4：水平尾翼面積を計算**

```
S_h = (V̄_h × S × c̄) / l_h
    = (0.10 × 0.28 × 0.176) / 0.60
    = 0.0082 m²
```

→ これは小さすぎるので、別のアプローチが必要

**調整案：K_n を小さくする（重心を後ろへ）**

K_n = 0.08 とすると：
```
C_m_alpha_wb = -0.08 × 4.0 = -0.32
C_m_alpha_h = -0.50 - (-0.32) = -0.18

V̄_h = 0.18 / 1.995 = 0.09（まだ小さい）
```

**実用的な設計：**
- V̄_h = 0.40～0.50 程度に設定
- K_n を調整して目標の C_m_alpha を実現

#### 例2：目標 C_n_beta = 0.30 を実現する

**与えられた条件：**
- S = 0.28 m², b = 1.59 m
- l_v = 0.60 m
- 胴体の寄与 C_n_beta_fus ≈ +0.15

**ステップ1：垂直尾翼の寄与を決定**

```
C_n_beta_v = 0.30 - 0.15 = 0.15
```

**ステップ2：必要な V̄_v を計算**

```
C_n_beta_v = η_v × V̄_v × C_L_alpha_v
0.15 = 0.95 × V̄_v × 3.5

V̄_v = 0.15 / (0.95 × 3.5)
     = 0.15 / 3.325
     = 0.045
```

**ステップ3：垂直尾翼面積を計算**

```
S_v = (V̄_v × S × b) / l_v
    = (0.045 × 0.28 × 1.59) / 0.60
    = 0.0200 / 0.60
    = 0.0334 m²
```

→ これは妥当な値です

## 設計手順の実例

### 完全な設計フロー

ここでは、仕様から完全に機体を設計する手順を示します。

#### ステップ1：要求仕様の定義

**目標UAVの仕様：**
- 全備重量: 1.7 kg
- 巡航速度: 15 m/s
- 飛行時間: 30分
- 安定性: 標準（初心者でも飛ばせる程度）

#### ステップ2：主翼の設計

**2-1. 翼面積の決定**

```
S = (m × g) / (0.5 × ρ × V² × C_L) × 安全率
  = (1.7 × 9.81) / (0.5 × 1.225 × 15² × 0.5) × 1.2
  = 0.24 × 1.2
  = 0.288 m²
```

採用値: **S = 0.28 m²**

**2-2. アスペクト比の選択**

長時間飛行のためAR = 9 を選択

```
b = √(AR × S) = √(9 × 0.28) = 1.59 m
c̄ = S / b = 0.28 / 1.59 = 0.176 m
```

採用値: **b = 1.6 m, c̄ = 0.175 m**

**2-3. 上反角の決定**

標準的な安定性のため Γ = 4° を選択

```
C_l_beta ≈ -4.0 × (4/57.3) × 0.9 = -0.25（理論）
```

実効値: **C_l_beta ≈ -0.15** ✓

**2-4. 主翼取付角**

巡航時の機体姿勢を考慮して **i_w = 2°** とする

```
C_L_0 = 4.0 × 0.0349 + 0.15 = 0.29 ≈ 0.30
```

#### ステップ3：重心位置の決定

スタティックマージン K_n = 0.10 を目標

```
x_cg = (0.25 + 0.10) × c̄
     = 0.35 × 0.175
     = 0.061 m = 61 mm（主翼前縁から）
```

#### ステップ4：水平尾翼の設計

**4-1. 容積比の決定**

標準的な値として **V̄_h = 0.45** を選択

**4-2. テールアームの決定**

機体全長を考慮して **l_h = 0.60 m** とする

**4-3. 水平尾翼面積**

```
S_h = (V̄_h × S × c̄) / l_h
    = (0.45 × 0.28 × 0.175) / 0.60
    = 0.037 m²
```

**4-4. 空力係数の計算**

```
C_m_alpha_wb = -K_n × C_L_alpha = -0.10 × 4.0 = -0.40
C_m_alpha_h = -0.95 × 0.45 × 3.5 × 0.6 = -0.90
C_m_alpha_total = -0.40 + (-0.90) = -1.30（理論値）
```

実効値（干渉効果）: **C_m_alpha ≈ -0.50** ✓

```
C_m_q = -2 × 0.95 × 0.45 × 3.5 × (0.60/0.175)
      = -10.2（理論値）
```

実効値: **C_m_q ≈ -4.0** ✓

```
C_m_delta_e = -0.95 × 0.45 × 0.50 × 1.5
            = -0.32（基本）
```

効率考慮: **C_m_delta_e ≈ -0.55** ✓

#### ステップ5：垂直尾翼の設計

**5-1. 容積比の決定**

標準的な値として **V̄_v = 0.04** を選択

**5-2. 垂直尾翼面積**

```
S_v = (V̄_v × S × b) / l_v
    = (0.04 × 0.28 × 1.6) / 0.60
    = 0.030 m²
```

**5-3. 空力係数の計算**

```
C_n_beta_v = 0.95 × 0.04 × 3.5 = 0.133
C_n_beta_fus ≈ 0.15
C_n_beta_total = 0.133 + 0.15 = 0.28 ≈ 0.30
```

✓

```
C_n_r = -2 × 0.95 × 0.04 × 3.5 × (0.60/1.6)
      = -0.099（尾翼のみ）
```

主翼と胴体の寄与を加えて: **C_n_r ≈ -0.40** ✓

#### ステップ6：検証と調整

**作成したパラメータをシミュレータに入力して検証：**
